# GCP Real-Time Streaming Pipeline 🚀

## Overview

This project demonstrates a real-time event streaming pipeline using Google Cloud Platform.

Events are generated by applications, published through Pub/Sub, processed using Dataflow streaming pipelines, and stored in BigQuery for analytics.


## Architecture
Event Producer
|
↓
Google Cloud Pub/Sub
|
↓
Dataflow Streaming Pipeline
|
↓
BigQuery
|
↓
SQL Analytics



## Technologies Used

- Python
- Apache Beam
- Google Cloud Pub/Sub
- Google Cloud Dataflow
- BigQuery
- SQL


## Pipeline Flow

### 1. Event Generation

Application events are generated in JSON format.

Example events:
- User activity
- Product views
- Purchases


### 2. Streaming Ingestion

Pub/Sub receives incoming messages and acts as the messaging layer.


### 3. Data Processing

Dataflow performs:

- JSON parsing
- Data transformation
- Validation
- Processing logic


### 4. Data Storage

Processed events are stored in BigQuery using a defined schema.


### 5. Analytics

SQL queries provide:

- Event analysis
- Revenue metrics
- User activity analysis
- Product performance
