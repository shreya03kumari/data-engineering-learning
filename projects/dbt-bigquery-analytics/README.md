# dbt + BigQuery Analytics Engineering Project 🚀

## Overview

This project demonstrates an analytics engineering workflow using dbt and Google BigQuery.

The project transforms raw customer transaction data into analytics-ready models following modern data warehouse practices.

## Architecture
Raw Data
|
↓
BigQuery Raw Layer
|
↓
dbt Transformations
|
↓
Analytics Models
|
↓
Business Reports


## Technologies Used

- dbt
- Google BigQuery
- SQL
- Data Modelling
- Data Quality Testing

## Data Pipeline Flow

1. Raw data is loaded into BigQuery
2. dbt models transform raw tables
3. Business logic is applied
4. Data quality tests validate models
5. Analytics tables are created
